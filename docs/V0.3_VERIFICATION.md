## Defects found by these tests and fixed

1. `require_external_workdir` resolved the work directory but not the inspected project, so on
   macOS (`/var` → `/private/var`) a work directory *inside* the project was accepted. Both
   sides are now resolved before comparison.
2. The commit being pushed was never compared against the approved manifest. A tracked file
   excluded as "review required" would still have been published because it is part of the
   commit. The pushed tree is now compared with the manifest in both directions and the upload
   is refused on any difference.

An earlier smoke run also demonstrated the history gate working: a project that had committed
`.env`, a `.sqlite3` file and a backup archive in its only commit was refused at plan time,
with the denied paths reported from the project's history.
